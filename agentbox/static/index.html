交件處

把 Facebook 給你的 ZIP 檔交進來。Facebook 若拆成好幾個 ZIP，一次全部選取。不用先解壓。

把 ZIP 拖到這裡 或
  • 會放上銀幕的：你的貼文文字，以及貼文和相簿裡的照片，依年份挑選。
  • 不會讀的：私訊、留言、朋友名單。
  • 不會上傳：檔案只在這台電腦的瀏覽器裡拆解。關掉分頁就消失，也可以隨時按「清空本場資料」。
  • 送給 GMI 模型的時候：你主動按「AI 剪輯」或「第二人生」時，才會把貼文文字、照片縮圖和個人檔案裡的經歷送給 GMI 模型分析，由 GMI Cloud 上的模型處理，按下去之前會先說明。
還沒匯出？怎麼跟 Facebook 要資料
  1. 到 Facebook 設定裡的帳號管理中心，找「你的資訊與權限」底下的「匯出你的資訊」或「下載你的資訊」。
  2. 選 Facebook 個人檔案，時間範圍選全部。
  3. 格式選 JSON，不要選 HTML；媒體畫質選高。
  4. 至少勾選貼文，以及相片和影片。
  5. Facebook 準備好會通知你，下載所有 ZIP 分卷。

AI 剪輯室

GMI Cloud

讓 GMI 模型讀完你這些年的貼文、看過你的照片，找出人生的主軸，挑出真正有轉折的段落，剪成一部有結構的片。畫面上的每一句仍然是你的原文。

  1. 閱片逐則判斷每篇貼文是轉折、心情、日常，還是轉貼、宣傳、玩笑。
  2. 看照片把照片排成縮圖表交給 GMI 模型，分辨生活照和廣告圖，數出人臉，有臉的優先。
  3. 寫結構找主軸，依真正的轉折分幕，每幕挑四到七個段落，找出相隔多年的前後呼應。

人生自畫像

照片馬賽克

用這些年的照片，拼出一張臉。每一格都是一張你的照片，照片越多，臉越清楚。

一、底圖

最好是正面、臉佔畫面一半以上、背景單純的大頭照。

先選一張底圖。

二、照片

每張照片的內容不變，只把色調往底圖那一格靠近。越高臉越清楚，越低越看得出原本的照片。

照片只在這台電腦的瀏覽器裡處理，不會上傳。

讀照片

照片多的話需要一兩分鐘。

滾輪放大，拖曳移動，滑到任一格可以看是哪一天的照片。這張自畫像會在正片結尾出現。

第二人生

本片純屬虛構

選一個人生的分岔點，寫下當時沒選的那條路。AI 會讀你前後幾年寫的字，推演另一部片。這部片是虛構的，和真實的片分開放映，字卡會標示「虛構」。

一、星盤（選填，可以跳過）

先排出你的星盤、說明命格，推演第二人生時會把它當成角色設定。沒有出生資料就直接跳到第二步。

完整星盤數據
